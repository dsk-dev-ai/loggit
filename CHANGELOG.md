# Changelog

All notable changes to loggit are documented here.

## [1.0.1] — 2026
### Changed
- Publish pipeline migrated to token-based upload, fixing the PyPI trusted-publisher
  403 on tag pushes.

## [1.0.0] — 2026
### Added
- **Stable 1.0.0 release.** A friendly terminal git history explorer: colorful commit
  browser, `--limit`, `--author`, `--branch`, `--oneline`, `--date`, and interactive
  pager navigation. Zero dependencies, Python 3.8+.
- Automated CI, Docker image, and PyPI publishing.
